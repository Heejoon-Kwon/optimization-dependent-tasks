# Flowline · 작업 순서 설계

작업 이름, 소요 시간, 선행 작업을 입력하면 Java 서버가 추천 직렬 실행 순서, 직렬 총시간, 병렬 최소시간을 계산합니다. 웹 화면의 DAG에서 임계 경로는 파란색으로 표시됩니다. 작업을 선택하면 연결된 선행·후속 작업과 병렬 기준의 시작·종료 시각, **여유 시간**을 확인할 수 있습니다.

## 실행

Java 17 이상과 Maven 3.9가 필요합니다.

```sh
mvn package
java -jar target/flowline.jar
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다. 서버 주소와 포트는 환경 변수 `HOST`와 `PORT`로 변경할 수 있습니다.

## 사용법

1. 카페 예제로 시작하거나, **예제** 메뉴에서 월간 보고서 또는 빈 목록을 선택합니다.
2. 작업별 이름과 양의 정수 소요 시간(분)을 입력합니다. 해당 작업 전에 완료해야 하는 작업을 **선행 작업**에서 번호와 이름으로 선택합니다. 뒤에 입력된 작업도 선택할 수 있습니다.
3. **작업 분석하기**를 누릅니다. 순환 의존성이 있으면 수정할 수 있도록 순환에 포함된 작업 번호를 표시합니다.

입력한 목록은 현재 브라우저에 저장됩니다. 작업을 삭제하면 해당 작업을 가리키는 선행 관계도 함께 제거됩니다.

## 계산 기준

- **직렬 총시간**은 사람이 한 명이고 작업을 쉬지 않고 진행할 때의 완료 시간입니다. 시간과 선행 관계가 고정돼 있으면, 조건을 만족하는 모든 순서의 총시간은 작업 시간의 합입니다. 추천 순서는 현재 시작할 수 있는 작업 중 해당 작업에서 이어지는 가장 긴 경로의 남은 시간이 큰 작업을 먼저 선택합니다. 값이 같으면 번호가 작은 작업부터 배치합니다.
- **병렬 최소시간**은 동시에 작업할 수 있는 인력이 충분할 때의 가장 이른 완료 시간입니다. 이 시간을 결정하는 **임계 경로**는 소요 시간의 합이 가장 긴 의존성 경로입니다. 최대 길이의 경로가 여러 개면 그래프에 모두 강조하고, 범례 아래에는 그중 하나를 표시합니다. 여유 시간은 병렬 최소시간을 유지하면서 해당 작업의 시작을 늦출 수 있는 시간입니다.
- 카페 예제에서 직렬 총시간은 **34분**, 병렬 최소시간은 **20분**입니다. 카페의 물리적 동선까지 최적화하려면 작업 간 이동 시간이나 위치를 추가로 모델링해야 합니다.

## 구현

Java의 인접 리스트와 진입 차수 배열로 DAG를 구성합니다. Kahn 위상 정렬과 정방향·역방향 동적 계획법으로 임계 경로와 여유 시간을 계산하는 비용은 `O(V + E)`입니다. 추천 직렬 순서는 `PriorityQueue`를 사용하며 `O(E + V log V)`에 계산합니다. HTML, CSS, JavaScript 화면은 같은 Java 서버에서 제공됩니다.

`POST /api/schedule`은 다음 형식의 JSON을 받습니다. 번호는 서로 다른 양의 정수이며, 작업은 1~100개, 작업 이름은 1~80자, 소요 시간은 1~1,000,000분입니다.

```json
{
  "tasks": [
    { "id": 1, "name": "자료 수집", "duration": 20, "prerequisites": [] },
    { "id": 2, "name": "보고서 작성", "duration": 30, "prerequisites": [1] }
  ]
}
```

응답에는 `serialDuration`, `parallelDuration`, `serialOrder`, `criticalPath`, `timings`, `edges`가 들어 있습니다. `mvn test`로 계산 로직의 테스트를 실행할 수 있습니다.

# Flowline · 작업 순서 설계

자원 수량과 작업의 선행 조건을 입력하면 Java와 OR-Tools CP-SAT으로 모든 작업의 완료시간을 최소화합니다. 웹에서 작업별 시작·종료 시각, 자원 점유, DAG의 임계 경로를 확인할 수 있습니다.

## 실행

Java 17 이상과 Maven 3.9가 필요합니다.

```sh
mvn package
java -jar target/flowline.jar
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 엽니다. 서버 주소와 포트는 환경 변수 `HOST`와 `PORT`로 변경할 수 있습니다.

## 사용법

1. **자원 목록**에 작업자, 장비 등의 이름과 동시에 사용할 수 있는 수량을 입력합니다. 각 자원에는 `R01` 같은 번호가 붙습니다.
2. **작업 목록**에 이름과 소요 시간(분)을 입력합니다. **선행 작업**에서 완료되어야 하는 작업 번호를, **사용 자원**에서 점유하는 자원 번호와 수량을 선택합니다.
3. **작업 분석하기**를 누릅니다. **실행 일정** 그래프의 점선은 작업 사이의 자원 인계 순서입니다. **선행 관계만** 보기에서는 원래 입력한 DAG와 의존성만으로 계산한 임계 경로를 확인할 수 있습니다.

자동 작업은 소요 시간을 그대로 입력하고 점유하는 자원만 선택합니다. 예를 들어 **버튼 조작**은 작업자, 그 뒤의 **장비 예열**은 장비를 점유합니다. 자원을 선택하지 않은 작업은 선행 작업이 끝나는 즉시 시작할 수 있습니다. 카페 예제는 작업자 1명으로 **13분**, 2명으로 **11분**입니다.

현재 입력은 같은 브라우저에서 자동 복원됩니다. 여러 주제를 보관하려면 **주제 이름**을 입력하고 **파일 저장**을 눌러 `.flowline.json` 파일을 내려받으세요. **파일 열기**로 원하는 파일을 불러와 수정한 뒤 다시 저장할 수 있습니다. 열어 둔 파일을 직접 덮어쓰려면 브라우저의 저장 대화상자에서 같은 파일을 선택하세요.

파일에는 주제 이름, 자원, 작업, 선행 관계와 자원 사용량이 들어갑니다. 작성 중인 목록도 저장할 수 있으며, 불러온 목록으로 **작업 분석하기**를 눌러 결과를 다시 계산할 수 있습니다. 작업이나 자원을 삭제하면 해당 번호를 참조하는 선행 관계나 자원 선택도 함께 제거됩니다.

## 계산 기준

- 작업의 소요 시간은 고정되며, 시작된 작업은 끝날 때까지 중단 없이 필요한 자원을 모두 점유합니다. 동일 자원 번호의 단위는 서로 대체할 수 있습니다.
- Kahn 위상 정렬과 DAG 최장 경로로 **의존성 하한**을 계산합니다. CP-SAT은 각 작업의 시작·종료 시각을 정하고, 같은 시간에 사용되는 자원 수가 용량을 넘지 않도록 자원별 `Cumulative` 제약을 적용합니다. 목적함수는 모든 작업을 완료하는 시각입니다.
- 계산된 일정에서 같은 자원 단위를 연이어 쓰는 작업을 연결하고, 자원 배치를 유지하며 작업을 가능한 가장 이른 시각에 배치합니다. 이 DAG에서 가장 긴 경로가 **실행 일정의 임계 경로**입니다. 동률인 임계 경로가 여러 개면 그래프에서 모두 강조합니다.
- CP-SAT 탐색 한도는 5초입니다. 최단임이 증명된 일정에는 **최적 확인**을 표시합니다. 한도 안에 증명하지 못하면 계산한 일정의 완료시간과 하한을 함께 표시합니다. 자원 점유가 없는 입력은 DAG 계산만으로 최적 해를 구할 수 있습니다.

## API

`POST /api/schedule`은 다음 형식의 JSON을 받습니다. 작업과 자원 번호는 각 목록에서 고유한 양의 정수입니다. 작업은 1~100개, 자원 종류는 0~100개입니다. 자원 용량은 1~100, 작업 소요 시간은 1~1,000,000분입니다. 작업별 사용량은 해당 자원의 용량 이하여야 합니다.

```json
{
  "resources": [
    { "id": 1, "name": "작업자", "capacity": 2 },
    { "id": 2, "name": "커피 머신", "capacity": 1 }
  ],
  "tasks": [
    { "id": 1, "name": "버튼 조작", "duration": 1, "prerequisites": [],
      "demands": [{ "resourceId": 1, "quantity": 1 }] },
    { "id": 2, "name": "예열", "duration": 8, "prerequisites": [1],
      "demands": [{ "resourceId": 2, "quantity": 1 }] }
  ]
}
```

`resources`나 `demands`를 생략하면 빈 목록으로 처리합니다. 응답의 `optimized`에 전체 완료시간, 증명된 하한, 최적 여부, 실행 일정, 임계 경로와 자원 인계 간선이 들어 있습니다. 기존 의존성 계산 결과도 응답에서 확인할 수 있습니다.

`mvn test`로 계산 로직의 테스트를 실행할 수 있습니다.
